# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Ariadne, please report it
privately. **Do not** open a public GitHub issue, pull request, or
discussion for security matters.

Send a report to: **ariadne.switch027@passinbox.com**

Please include, where possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a minimal proof-of-concept
- The affected version or commit
- Any suggested mitigation

You will receive an acknowledgement within a reasonable timeframe.
Coordinated disclosure is appreciated — please give a fix the chance to
land before public discussion.
